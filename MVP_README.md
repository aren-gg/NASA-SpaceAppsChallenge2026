# Weather prototype

The survival MVP has been replaced by the standalone weather module.

Open `My project/Assets/MarsWeather/Scenes/WeatherPreview.unity` in Unity 2022.3 and press Play. Use the five buttons or keys 1–5 to switch weather.

See [MarsWeather integration guide](My%20project/Assets/MarsWeather/README.md) for prefab installation, activation API, dependencies, and ownership boundaries.
